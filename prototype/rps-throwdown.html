What changed

  1. A stage replaces the white card. The robot stands on concrete tinted with its body color. You stand on purple grip tape. A steel coping runs between the two.
  2. The real gesture. Both fists pump on Rock… Paper… Scissors… and open on Shoot. The robot's hand points down at you, and yours points up at it.
  3. Drawn hands replace emoji. The hands use the robot's ink outline. You get a white glove with a purple cuff; the robot's hand uses its own body and accent colors. Emoji look different on every phone, and these hands don't.
  4. Winner takes ground. The coping slides into the loser's turf, the winning hand pushes forward, and the losing hand fades.
  5. The headline says what happens next: “You set first.” The rule (“Paper covers rock”) goes on a strip of tape across the coping.
  6. The robot reacts with poses it already has: stoked when it wins, bailed when it loses, plus one line of trash talk. It gets no new body parts.
  7. Stickers in the thumb zone. The three throws are die-cut stickers on the grip tape. After a tie they come straight back, so a tie never costs an extra tap.
  8. Start fills itself. The button fills over about 3 s and then starts the game. Tap it to start sooner.

How it maps to the code

This is a restyle plus one small SVG component. The rules and the timing stay the same.

Keeps

  • rps.ts is untouched. Same robotThrow, rpsOutcome, and BEATS.
  • RpsPanel phases stay the same: idle → counting → resolved → starting, with the same COUNTDOWN_WORDS and BEAT_MS = 450.
  • Feedback hooks: rpsSound / rpsVibrate fire on the same beats. This file plays stand-in blips.
  • Keyboard: R/P/S and 1/2/3 still throw. aria-live still announces the result.
  • GameStartAnimation still plays after Start (stubbed in this file).

Adds

  • RpsHand.tsx in features/game: three ~10-shape SVGs with a glove / robot palette. It replaces the emoji in RPS_CHOICES.
  • RobotAvatar pose is already there, so the reactions cost nothing.
  • Optional rpsLines on Robot (idle / win / lose / tie), with generic fallbacks, so trash talk can land roster by roster.
  • Layout: the scoreboard is already hidden during RPS, so the arena can take the full height under the topbar. It replaces the .rps-* block in globals.css.
  • Reduced motion: pumps, slams, and the coping slide collapse to instant state changes.
