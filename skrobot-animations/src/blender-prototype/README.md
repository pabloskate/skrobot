# Blender trick prototype

This directory is an intentionally isolated vertical slice. Production game
animation continues to use `@skrobot/animations`; nothing here is imported by
the web game.

## Contents

- `BlenderPrototype.tsx`: Three.js viewer used only by the standalone animation playground.
- `BlenderPrototype.module.css`: prototype-only presentation.
- `blender/generate_prototype.py`: deterministic Blender source for the robot, skateboard, and animation.
- `blender/generated/*.blend`: editable Blender scenes generated by the script.
- `../../public/blender-prototype/*.glb`: browser assets generated by the script.

## Matching the shipped robots

The prototype is meant to be visually indistinguishable from the 3D robots in
`packages/animations/src/TrickAnimation3D.tsx`. Blender owns geometry;
`@skrobot/animations` (`specFor` / `computeFrame`) owns motion;
`BlenderPrototype.tsx` owns the look (toon ramp, inverted-hull ink, sky/road/sun
scenery) and the trick/stance/outcome controls.

The GLB is loaded as a rest-pose rig — baked kickflip clips are ignored.
`poseFromFrame.ts` maps each physics frame onto the named empties
(`RobotRig`, `SkateboardRig`, `Rig.Hip.*`, …).

Every proportion in `generate_prototype.py` is a literal copied from
`TrickAnimation3D.tsx` — torso capsule width 20, head 22, legs 6.5, arms 6.25,
`SHOULDER_Z` 12, knee dot 3.6, and so on. That file draws capsules as *strokes*,
so a "width 20" there is a radius of 10 here. Read those numbers from the
source when something looks off; measuring them off a screenshot does not work,
because the shipped renderer uses a different projection and paints a heavy ink
stroke that inflates every shape.

## Rebuild

From the repository root:

```sh
/Applications/Blender.app/Contents/MacOS/Blender \
  --background --factory-startup \
  --python skrobot-animations/src/blender-prototype/blender/generate_prototype.py
```

## Removal

Delete this directory, `skrobot-animations/public/blender-prototype`, remove the
`blender` playground mode/import from `src/App.tsx`, and remove `three` plus
`@types/three` from the playground package.
