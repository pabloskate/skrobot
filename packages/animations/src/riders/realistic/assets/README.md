# Realistic skater assets

Built by `../blender/build_skater.py` (see `../blender/README.md`); don't edit
by hand. Every source asset is MakeHuman's, released as CC0
(<https://creativecommons.org/publicdomain/zero/1.0/>), so nothing here needs
attribution:

| File | Made from |
|---|---|
| `skater.glb` | MakeHuman base mesh and default rig (via MPFB 2), system eyes, `eyebrow008`, `eyelashes01`, `male_casualsuit06`, `shoes06`; the beanie is modelled by the build script. Skinned, scaled to world units, with baked vertex occlusion. |
| `skin.jpg` | system skin `young_caucasian_male` |
| `skin_normal.jpg` | `mindfront_aksel_skin` normal map (Skins 02 pack, by Mindfront) |
| `hair.jpg` | a short haircut's coverage, derived from system skin `young_african_male` |
| `outfit*.jpg` | `male_casualsuit06` color, normal and occlusion maps (the tee is recolored in the shader, its print unused) |
| `eye.jpg`, `brows.png`, `lashes.png` | system eye `brown`, `eyebrow008`, `eyelashes01` |

Sources: <https://static.makehumancommunity.org/assets/assetpacks.html>
("MakeHuman system assets" and "Skins 02").
